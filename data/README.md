# Data

This project uses two preprocessed datasets, both hosted on Zenodo due to
size constraints.

## CICIDS2017

`trainset.parquet` and `testset.parquet` (derived from CICIDS2017):

**https://doi.org/10.5281/zenodo.22339804**

Download both files and place them in this folder before running
`notebooks/ids_complete_experiments.ipynb`.

Original dataset citation:
Sharafaldin, I., Lashkari, A. H., & Ghorbani, A. A. (2018). "Toward Generating a
New Intrusion Detection Dataset and Intrusion Traffic Characterization."
4th International Conference on Information Systems Security and Privacy
(ICISSP), Portugal, January 2018.

## CIC-IDS-2018

`trainset_2018.parquet` and `testset_2018.parquet` (derived from CSE-CIC-IDS2018):

**https://doi.org/10.5281/zenodo.22543338**

Download both files and place them in this folder before running the
cross-dataset validation notebook.

Original dataset source:
Canadian Institute for Cybersecurity (CIC) and Communications Security
Establishment (CSE): https://www.unb.ca/cic/datasets/ids-2018.html
